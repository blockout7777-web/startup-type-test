120분 만에 만드는
창업가 유형 테스트

프롬프트를 복사해 AI에게 요청하고, VS Code에서 수정하고, Supabase에 결과를 저장한 뒤 GitHub Pages로 실제 URL까지 배포합니다.

12문항창업 성향 테스트
4유형IDEA · ACTION · DATA · PEOPLE
무료 DBSupabase 연동
실제 URLGitHub Pages 배포
💡
실습 방법 아래 단계를 위에서부터 순서대로 진행하세요. 각 단계의 프롬프트 복사 버튼을 누른 뒤 사용하는 AI 코딩 도구에 붙여넣으면 됩니다.

실습 목차

1. 프로젝트 만들기 2. 기본 화면 생성 3. 질문·점수 기능 4. 결과 화면 개선 5. Supabase 준비 6. DB 연결 7. 참여자 통계 8. 디자인 꾸미기 9. 오류 점검 10. GitHub 배포 완성 확인

단계별 실습

01

프로젝트 폴더 만들기

VS Code에서 실습용 폴더를 만들고 3개의 파일만 준비합니다.

목표 · index.html / style.css / script.js 생성
폴더명startup-type-test
파일 3개index.html · style.css · script.js
02

기본 웹페이지 생성

첫 번째 프롬프트로 테스트의 전체 뼈대를 만듭니다.

프롬프트 ① 기본 화면 만들기
VS Code에서 실행할 수 있는 웹페이지를 만들어줘.

프로젝트명은 "나는 어떤 창업가일까?"야.

HTML, CSS, JavaScript만 사용하고
index.html, style.css, script.js 3개의 파일로 분리해줘.

사용자가 12개의 질문에 답하면 다음 4가지 창업 유형 중 하나가 나오도록 만들어줘.

1. IDEA — 아이디어 탐험가
2. ACTION — 실행 돌격대장
3. DATA — 데이터 전략가
4. PEOPLE — 관계 연결자

조건:
- 첫 화면에 제목과 간단한 설명 표시
- 닉네임 입력칸 만들기
- "테스트 시작" 버튼 만들기
- 질문은 한 화면에 하나씩 표시
- 각 질문마다 선택지 4개 제공
- 선택하면 다음 질문으로 자동 이동
- 현재 질문 번호와 진행률 표시
- 총 12문항
- 가장 높은 점수 유형을 결과로 표시
- 결과에는 유형명, 설명, 강점, 주의점, 추천 역할 표시
- 모바일에서도 보기 좋게 반응형으로 제작
- 밝고 전문적인 스타트업 서비스 스타일
- 초보자가 이해할 수 있도록 중요한 JavaScript 부분에 한글 주석 추가
03

질문과 점수 기능 점검

질문이 자연스럽고 네 유형 점수가 제대로 계산되는지 확인합니다.

프롬프트 ② 질문·점수 개선
현재 만든 창업가 유형 테스트의 질문과 점수 로직을 점검해줘.

다음 기준으로 수정해줘.

- 총 12문항 유지
- 각 문항은 정답이 없는 성향 질문
- 각 질문의 선택지 4개는 IDEA, ACTION, DATA, PEOPLE에 각각 1점씩 연결
- 질문 주제는 다음을 골고루 포함
  1. 아이디어가 생겼을 때 행동
  2. 사업에서 중요하게 생각하는 것
  3. 팀에서 맡는 역할
  4. 문제가 생겼을 때 행동
  5. 제품 출시 방식
  6. 경쟁자 대응
  7. 고객 불만 대응
  8. 새로운 기술 대응
  9. 투자금 활용
  10. 실패 가능성 대응
  11. 팀원 채용 기준
  12. 창업 성공 조건
- 특정 유형이 유리해 보이지 않도록 문장을 균형 있게 작성
- 선택 즉시 다음 질문으로 이동
- 마지막 질문 뒤에는 결과 화면 표시
- 기존 디자인은 최대한 유지
04

결과 화면 완성

테스트 결과가 '공유하고 싶은 화면'처럼 보이게 만듭니다.

프롬프트 ③ 결과 화면 개선
현재 테스트의 결과 화면을 더 완성도 있게 개선해줘.

각 유형마다 다음 내용을 보여줘.

IDEA — 아이디어 탐험가
ACTION — 실행 돌격대장
DATA — 데이터 전략가
PEOPLE — 관계 연결자

결과 화면 구성:
- 유형 이모지 또는 간단한 아이콘
- 유형명
- 한 줄 설명
- 강점 3~4개
- 주의할 점 1~2개
- 추천 창업 역할
- IDEA, ACTION, DATA, PEOPLE의 점수를 막대 형태로 시각화
- "다시 테스트" 버튼
- 기존 테스트 기능은 변경하지 말 것
- 모바일에서도 보기 좋게 유지
05

Supabase 데이터베이스 준비

테스트 결과를 저장할 무료 DB를 만듭니다.

테이블명 · test_results
권장 컬럼

id              bigint
nickname        text
result_type     text
idea_score      integer
action_score    integer
data_score      integer
people_score    integer
created_at      timestamp
⚠️ 수업용 프로젝트에서는 개인의 민감정보를 저장하지 마세요. 닉네임 정도만 사용하는 것이 좋습니다.
06

Supabase 연결

테스트가 끝나면 결과가 실제 DB에 저장되게 합니다.

프롬프트 ④ DB 연결
현재 만든 창업가 유형 테스트에 Supabase 데이터베이스를 연결해줘.

Supabase JavaScript v2 CDN 방식을 사용해줘.

test_results 테이블에 다음 데이터를 저장해줘.

- nickname
- result_type
- idea_score
- action_score
- data_score
- people_score
- created_at

조건:
- 사용자가 테스트를 완료하면 결과를 Supabase에 저장
- 저장이 실패해도 결과 화면은 정상적으로 표시
- Supabase URL과 공개용 키는 script.js 상단에서 쉽게 수정하도록 작성
- URL과 Key를 입력할 위치에 한글 주석 표시
- 기존 테스트 기능과 디자인은 변경하지 않기
- 오류가 나면 console에 원인을 확인할 수 있도록 처리
💡 AI가 코드를 수정한 뒤 script.js 상단의 SUPABASE_URL, SUPABASE_KEY 값을 자신의 프로젝트 값으로 교체하세요.
07

참여자 통계 추가

DB를 읽어서 전체 참여자의 유형 분포를 보여줍니다.

프롬프트 ⑤ 통계 기능
Supabase의 test_results 데이터를 읽어서 결과 화면 아래에 전체 참여자의 창업가 유형 통계를 추가해줘.

조건:
- IDEA, ACTION, DATA, PEOPLE 각각의 참여 인원 계산
- 전체 참여자 수 표시
- 유형별 비율(%) 계산
- 막대그래프로 표시
- 참여 인원이 0명이어도 오류가 나지 않게 처리
- DB 데이터를 불러오지 못하면 "통계를 불러올 수 없습니다." 표시
- 테스트 결과 화면은 항상 정상적으로 유지
- 기존 기능은 삭제하지 않기
08

나만의 디자인 만들기

기능은 그대로 두고 색상과 분위기만 바꿉니다.

프롬프트 ⑥ 디자인 개선
현재 웹페이지의 기능은 절대 수정하지 말고 디자인만 개선해줘.

디자인 방향:
- 밝고 신뢰감 있는 스타트업 서비스 느낌
- 배경은 밝은 아이보리 또는 연한 회색
- 보라색 또는 파란색을 포인트 컬러로 사용
- 카드 모서리는 둥글게
- 버튼은 크고 명확하게
- 버튼 hover 효과 추가
- 질문 카드와 결과 카드를 구분
- 결과 유형별로 다른 이모지 사용
- 스마트폰에서도 버튼과 글자가 잘 보이도록 반응형 유지
- 너무 화려한 애니메이션은 사용하지 않기
🎨 같은 기능이라도 색상과 문구를 바꾸면 각자의 사업 아이디어로 쉽게 변형할 수 있습니다.
09

오류 점검

배포 전에 한 번에 점검하도록 AI에게 요청합니다.

프롬프트 ⑦ 최종 점검
현재 프로젝트를 배포하기 전에 전체 코드를 점검해줘.

점검 항목:
1. index.html, style.css, script.js 연결 오류
2. 테스트 시작 버튼 정상 작동
3. 12개 질문 정상 진행
4. 점수 계산 오류 여부
5. 결과 유형 정상 표시
6. Supabase 저장 성공 여부
7. Supabase 통계 조회 정상 작동
8. 모바일 화면 깨짐 여부
9. JavaScript 콘솔 오류 여부
10. GitHub Pages 같은 정적 호스팅에서 실행 가능한 구조인지 확인

문제가 있다면 수정해주고,
무엇을 수정했는지 초보자도 알 수 있도록 간단히 설명해줘.
10

GitHub Pages로 배포

완성한 프로젝트를 인터넷에 공개하고 URL을 만듭니다.

추천 저장소 이름 · startup-type-test
1GitHub에서 새 저장소 만들기
2index.html / style.css / script.js 업로드
3Settings → Pages 이동
4배포 후 생성된 URL 확인
예시 URL: https://사용자명.github.io/startup-type-test/
