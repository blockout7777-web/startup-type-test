구조적 불일치 4가지

  • 푸터 문구가 두 종류 — "VS Code 설치부터 바이브코딩 첫 세팅까지" / "Living AI 스타트업 육성교육 ㅣ 회사 홈페이지 만들기 (VS Code 실습)"
  • 진행 표시가 세 종류 — 막대+퍼센트(7%) / 막대+분수(10 / 30) / 막대만
  • 페이지 번호가 중간에 리셋 — 02·03… 진행 후 다시 10…30으로 시작 (두 개 덱을 합친 흔적)
  • 페이지 배지 색이 두 가지 — 진한 네이비 계열 / 밝은 파랑 계열
이 가이드의 목표 — 위 8가지를 하나의 값으로 고정합니다. 특히 타이틀 · 푸터 강의주제 · 페이지번호 3종은 어떤 슬라이드에서도 절대 크기를 바꾸지 않습니다.

03 타이포그래피 — Pretendard

전 슬라이드 Pretendard 한 종류만 사용합니다. 굵기 차이로 위계를 만들고, 다른 폰트를 섞지 않습니다.

폰트 설치

  • PPT · 키노트 — Pretendard 데스크톱 폰트 설치 후 사용 (github.com/orioncactus/pretendard)
  • 웹 · HTML 슬라이드 — CDN 링크로 불러오기 (이 문서도 같은 방식)
  • 대체 폰트 — 설치 불가 시 Malgun Gothic(맑은 고딕). 단, 자간이 달라 줄바꿈이 밀릴 수 있음
  • 코드·URL 표기는 고정폭 폰트(D2Coding · Consolas) 예외 허용

08 3D 아이콘 가이드

모든 아이콘은 3D 아이콘 한 가지 스타일로 통일합니다. 선 아이콘 · 이모지 · 실사 사진과 섞어 쓰지 않습니다.

스타일 규격 8가지

① 재질말랑한 클레이(clay) 느낌. 무광 바탕에 아주 옅은 광택 하이라이트 하나
② 모서리모든 모서리를 둥글게(rounded). 날카로운 각 금지
③ 시점정면에서 살짝 위, 3/4 각도로 일관. 아이콘마다 각도가 다르면 안 됨
④ 조명광원 1개, 왼쪽 위에서. 그림자는 오른쪽 아래로
⑤ 그림자아래쪽 부드러운 그림자, 불투명도 15~20%. 진한 그림자 금지
⑥ 색Violet 600 · Violet 400 · 회색 · Sand 300 + 흰색. 한 아이콘에 4색 이내
⑦ 배경반드시 투명 PNG. 흰 사각형이 남아 있으면 슬라이드에서 티가 남
⑧ 글자아이콘 안에 글자·숫자를 넣지 않음 (한글 깨짐·번역 문제)
